# 🍱 Surplus Food Donation Platform

A web-based platform that connects surplus food donors with local NGOs and shelters to reduce food waste and help people in need.

## Features
- Donor portal for posting surplus food
- NGO portal for viewing and claiming available donations
- City-based filtering
- Pickup address and time
- Donation status tracking
- Responsive design for mobile and desktop

## Technologies
- HTML5
- CSS3
- JavaScript

## Run locally
Open `index.html` in a web browser.

## GitHub Pages
Upload `index.html` to a GitHub repository and enable GitHub Pages to publish the website.
